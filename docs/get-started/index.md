# Get started with the Camel Integration Capability

The Camel Integration Capability (CIC) runs Apache Camel routes and serves the `ai-tool:` routes as MCP tools. Wanaku forwards tool calls from AI agents to it. These pages explain what CIC does and how to run it.

## Pages in this section

- [Camel Integration Capability](usage.md): run the capability, deploy it, and register it with Wanaku.
- [Architecture](architecture.md): the components, the data flow, and the design decisions.
